
# ASP.NET MVC Portfolio Project Rules

## Project Context
- This is an existing ASP.NET MVC portfolio website.
- The project uses C#, Razor (.cshtml), CSS and JavaScript.
- Understand the existing architecture before making changes.

## Token Optimization
- Never scan the entire project unnecessarily.
- Read only files relevant to the requested task.
- Do not repeatedly read files already understood.
- Avoid reading bin, obj, .vs and generated files.
- Do not generate lengthy explanations.
- Prefer small, targeted code changes.

## Code Modification Rules
- Preserve existing functionality.
- Do not rewrite the entire website.
- Reuse existing layouts, partial views and CSS classes.
- Avoid duplicate CSS and JavaScript.
- Follow the existing naming conventions.
- Keep Razor syntax valid.
- Maintain responsive design for mobile, tablet and desktop.
- Do not introduce unnecessary NuGet or npm packages.

## Design Rules
- Maintain a modern, professional portfolio design.
- Keep UI consistent across all pages.
- Use reusable CSS components.
- Avoid inline CSS unless absolutely necessary.
- Keep JavaScript modular and maintainable.

## Safety
- Before modifying files, inspect the relevant code.
- Explain the planned changes briefly.
- Do not delete existing files without permission.
- Do not modify database configuration or secrets.
- Do not change unrelated functionality.

## Verification
- Build the project after significant C# changes.
- Check Razor syntax and CSS/JS references.
- Report changed files and any remaining issues.
